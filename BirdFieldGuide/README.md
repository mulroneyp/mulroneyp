# Field guide

An iPhone field guide. Open `BirdFieldGuide.xcodeproj` in Xcode, pick the BirdFieldGuide scheme, and run it on an iPhone simulator or a phone.

Greater Melbourne is the default place: 77 species, with habitat notes, height icons, and openly licensed photos. Choose another suburb or town from the location control. Places inside greater Melbourne keep that species list and aim the “where you find it” notes at the suburb. San José, Costa Rica is its own coverage: a 16-species starter sample of common Central Valley birds, not a notes export and not a full checklist. If a place is outside both sets, the app says so and shows the closest coverage it actually has.

Photos live in `BirdFieldGuide/Resources/images`. Credits are in `BirdFieldGuide/Resources/guide.json` and under each photo. Licences are public domain, CC0, CC BY, CC BY-SA, or GFDL.

This project was assembled on a Linux machine without Xcode. It has not been compiled or run in the iOS simulator here.
