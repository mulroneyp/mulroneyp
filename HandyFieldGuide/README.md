# Handy Field Guide

An iPhone field guide. Open `HandyFieldGuide.xcodeproj` in Xcode, pick the HandyFieldGuide scheme, and run it on an iPhone simulator or a phone. No development team is set, so Xcode will ask for one before a device build.

The place is yours to type. An empty location opens the Children's Eternal Rainforest checklist for Monteverde: 171 species taken from the San Gerardo station list. Tiers are mid-late November estimates, not eBird frequencies. San Gerardo and Bajo del Tigre are presets on that same list. Bajo del Tigre is drier secondary forest, so the Tier 3 and Tier 4 forest-interior birds are less expected there. Greater Melbourne is a second, smaller list. If a place is outside both, the app says so and shows the closest list it actually has. It does not invent birds.

Photos live in `HandyFieldGuide/Resources/images`. Credits are in `HandyFieldGuide/Resources/guide.json` and under each photo. Licences are public domain, CC0, CC BY, CC BY-SA, or GFDL.

This project was assembled on a Linux machine without Xcode. It has not been compiled or run in the iOS simulator here.
